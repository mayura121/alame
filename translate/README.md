# VoiceBridge — リアルタイム音声翻訳・通訳ツール

話した言葉をその場で相手の言語に翻訳し、**画面に表示＋読み上げ**するブラウザツールです。
言語の違う相手との交流会・配信・通話のために作った「通訳器」です。インストール不要・キー不要で動きます。

公開URL（予定）: https://alame.pages.dev/translate/

## できること（MVP）

- 🎤 **音声で話す → 認識 → 翻訳 → 表示＋読み上げ**（コアの通訳ループ）
- 👫 **2言語モード**：「あなた」と「相手」の言語を選び、ボタンで話者を切り替え
- 🖥️ **提示モード**：最新の翻訳を画面いっぱいに大きく表示（相手に見せる／配信・画面共有に重ねる）
- ⌨️ マイク非対応端末（Safari / Firefox 等）向けに **文字入力**でも翻訳可
- 🔁 連続認識、🔊 読み上げ ON/OFF、言語入れ替え、16言語対応
- 📱 PWA（ホーム画面に追加してアプリとして使用可・オフラインUI対応）

## 設計：エンジンを差し替えられる構造

`translate(text, from, to)` を1つの関数に集約しています。

- 既定：**MyMemory**（無料・APIキー不要・CORS対応）= まず動かすため
- 設定 → エンジン → **カスタムサーバー** にすると、自前のエンドポイント
  （`POST {text, from, to}` → `{translatedText}`）に差し替え可能。
  将来 DeepL や自前のAI通訳サーバーに繋ぐための受け口です。

## ロードマップ（構想）

この MVP の「話す→認識→翻訳→出力」ループを**共通エンジン**として、次へ繋げます。

1. **通訳ツール（このアプリ）** ← いまここ
2. **配信オーバーレイ**：翻訳テロップを Discord / OBS に重ねる
3. **VRChat アバター連携**：自分が話した内容をアバターが同時通訳で代弁
4. **ペット／追従アイテム向け AI＋翻訳プラグイン**

> ②〜④は外部連携・配布形態の検討が必要なため別工程。まずは①を磨いて土台にする方針。

## ローカルで動かす

```bash
npx serve -l 5500 .
# → http://localhost:5500/translate/
```

音声認識（Web Speech API）は **Chrome / Edge** で安定動作します。
マイク利用には HTTPS もしくは localhost が必要です。
